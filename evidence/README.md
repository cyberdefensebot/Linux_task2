# Evidence

This directory is for genuine evidence collected while performing the actual lab.

## Evidence rules

Do not create fake screenshots, fake terminal output, or fabricated results.

## What to capture

After the actual lab document is supplied, document each required evidence item here.

Suggested format:

| Evidence | When to capture | What it proves |
|---|---|---|
| `01-[description].png` | After step [X] | [Requirement demonstrated] |
| `02-[description].png` | After step [X] | [Requirement demonstrated] |

## Terminal output

Place relevant captured output in `terminal-output/` when the lab requires it.

## Suggested naming

Use sequential, descriptive names such as:

```text
01-environment-ready.png
02-task-result.png
03-verification.png
04-final-state.png
```

These are examples only. Rename them to match the actual lab.

## Before submission

- [ ] Every required screenshot captured
- [ ] Screenshot names are meaningful
- [ ] Screenshots show enough context to prove the result
- [ ] Terminal output is genuine
- [ ] No evidence has been fabricated
