## Submission instructions

The actual academic submission requirements must be taken from the technical lab/activity document.

## Before submitting

- [ ] Read the actual lab's submission instructions
- [ ] Confirm all required tasks are complete

- [ ] Confirm command history is saved

- [ ] Remove accidental personal secrets or credentials
- [ ] Review the repository
- [ ] Commit and push if GitHub submission is required

## Important
